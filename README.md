# Minimal Astro portfolio

## Run locally

Install the dependencies, then start Astro:

```bash
npm install
npm run dev
```

## Updating content

All copy, links, contact details, and photo URLs are in [`src/data/portfolio.ts`](./src/data/portfolio.ts). Edit that one file and Astro refreshes the site automatically during local development.

For straightforward updates from any device, connect the repository to Netlify. You can edit `src/data/portfolio.ts` in GitHub’s web editor; saving the change triggers a new deployment.
